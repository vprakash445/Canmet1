PART 1 — MODULE CARD IMAGES (shown on Home Screen)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Location: assets/images/modules/

These 7 images appear as the background of each module card on the 
home screen. Recommended size: 600 x 400 pixels (JPG or PNG).

  File name                  Module
  ─────────────────────────  ────────────────────────
  edumet_card.png            EduMET (Metabolic Education)
  nutrimet_card.png          NutriMET (Healthy Eating)
  physimet_card.png          PhysiMET (Exercise)
  safemet_card.png           SafeMET (Clinical Safety)
  trackmet_card.png          TrackMET (Self Monitoring)
  mindmet_card.png           MindMET (Stress & Sleep)
  medimet_card.png           MediMET (Medication)

HOW TO REPLACE:
  1. Prepare your image (JPG/PNG, ideally 600x400 px)
  2. Name it exactly as shown above (e.g. nutrimet_card.png)
  3. Replace the file in assets/images/modules/
  4. Done! No code changes needed.

NOTE: These card images are the SAME for both Hindi and English.
If you want different card images per language, let me know.

PART 3 — HOW TO REPLACE IMAGES (Step by Step)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FOR ENGLISH IMAGES:
  1. Prepare your image (PNG or JPG, recommended 800x500 px)
  2. Navigate to: assets/images/MODULENAME/en/
  3. Replace the file — keep the EXACT same filename
     Example: replace nutrimet/en/section1.png with your millet image

FOR HINDI IMAGES (different image for Hindi users):
  1. Prepare your Hindi version image (same size)
  2. Navigate to: assets/images/MODULENAME/hi/
  3. Replace the file with the EXACT same filename
     Example: replace nutrimet/hi/section1.png with your Hindi millet image

IF YOU WANT SAME IMAGE FOR BOTH LANGUAGES:
  Just put the same image file in both /en/ and /hi/ folders.

PART 4 — IMAGE TIPS & BEST PRACTICES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ Recommended format: PNG (transparent background) or JPG
✅ Recommended size: 800 x 500 pixels for sections, 600 x 400 for cards
✅ Keep file size under 500KB for fast loading
✅ Use infographic-style images (like the ones shared earlier)
✅ For medical images, use simple diagrams — avoid real patient photos

❌ Do NOT change the file NAME — only replace the file content
❌ Do NOT change the folder structure
❌ Do NOT use WEBP format (may not work on older Android)

PART 5 — AFTER REPLACING IMAGES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

After replacing images, you need to rebuild the APK:

Option A (GitHub Actions — Recommended):
  1. Upload the updated assets/images/ folder to your GitHub repo
  2. GitHub Actions will automatically build a new APK
  3. Download the new APK from Actions > Artifacts

Option B (Local build):
  cd canmet_app
  flutter pub get
  flutter build apk --release
  APK at: build/app/outputs/flutter-apk/app-release.apk

NO CODE CHANGES NEEDED — just replace the image files!
